# Tentang
Sesi 6, Sistem dashboard untuk deteksi deformasi

## Cara Menjalankan

**Clone & Install Dependensi:**
   ```bash
   pip install -r requirements.txt
   ```

**Jalankan Aplikasi Server:**
   ```bash
   python app.py
   ```

**Buka di Browser:**
   Akses `http://localhost:8000` untuk membuka dashboard
